星屿 · Telescope Garden —— 星环教学中枢 · 学习资源内嵌版
==========================================================

一、这是什么
------------
「星屿」原本是 Telescope Garden 1.0.0（Windows 桌面天文摆件，Godot 4.7 制作）。
本包把它的**原版 3D 设备模型**和**真实星表 / 天文算法**移植成网页版，
内嵌在星环教学中枢的「学习资源」页里，点一下就能用，不需要安装任何东西。

二、怎么打开
------------
1. 解压整个压缩包（不要只解出 index.html）。
2. 双击 index.html，用 Edge / Chrome 打开。
3. 用成员账号登录 → 顶栏出现「学习资源」→ 页面最上方就是「星屿」卡片 → 点「进入星屿」。
   （学习资源页和其他中枢页一样，需要登录后从顶栏进入。）

   也可以直接把网站部署到静态托管（如腾讯云 CloudBase 静态网站）后再访问，行为一致。

三、里面能做什么
----------------
· 观测地：北京 / 上海 / 阿里 / 阿塔卡马 / 堪培拉 / 武汉，各自的经纬度与时区（含夏令时）。
· 目标：M1–M110 与 80 个精选目标，共 190 个真实天体，可按类型筛选、按名称搜索。
· 时间：1× / 60× / 240× / 480× / 1440× 倍速；「前往夜晚」一键跳到太阳低于 -22° 的时刻。
· 望远镜：折射镜 76SAP / 施卡 SCT / 牛顿反射 200PDS 三种主镜，单反 / 冷冻相机，导星镜可开关。
· 跟踪：选中目标后望远镜自动转向并持续跟踪；目标落下或天亮会自动停止。
· 拍摄：与桌面版相同的判定——太阳低于地平线 18°、目标高于 5°，每帧 60 秒模拟曝光。
· 读数：本地时间、恒星时、太阳高度、月亮亮度与高度、目标高度与方位、曝光帧数与累计积分。
· 全天星图：天顶投影，含地平圈、方位标注、太阳与月亮轨迹、全部目标位置。

四、关于云函数（重点）
----------------------
**不需要新增任何 SCF 云函数，也不需要新建数据库集合。**

· 3D 模型（.glb）与星表（targets.json、timezones.json）都已用 base64 / JS 内嵌在
  xingyu/xingyu-models.js 与 xingyu/xingyu-data.js 里，运行时不发任何网络请求。
· 星历（太阳、月亮、恒星时、岁差）全部在浏览器里计算，不调用后端。
· 站点原有的登录、课堂、资料等接口保持不变；本模块从不请求它们。
· 因此断网、本地双击打开也能完整运行。

唯一需要注意的是：三个第三方库（three.js / GLTFLoader / OrbitControls）已随包放在
xingyu/vendor/ 下，同样不依赖 CDN。

五、文件清单
------------
index.html                站点入口（新增了一行样式引用、一个脚本引用）
script.js / style.css     原有站点脚本与样式，未改动
app.v236.js               原有中枢逻辑，未改动
echarts.min.js            原有图表库，未改动
logo.png / nankai-logo.png 原有徽标
xingyu/                   新增的「星屿」模块
  xingyu.js               三维场景、天文计算、界面与交互
  xingyu.css              模块样式（沿用站点配色）
  xingyu-data.js          星表 190 条 + 时区表 + 月球级数表
  xingyu-models.js        10 个 .glb 模型（base64 内嵌，约 2.9 MB）
  vendor/three.min.js     three.js r147
  vendor/GLTFLoader.js    glTF 模型加载器
  vendor/OrbitControls.js 视角控制

六、体积与性能
--------------
整个模块约 4.1 MB（其中模型 2.9 MB）。采用**按需加载**：打开学习资源页时不会
加载它，只有点了「进入星屿」才开始下载并装配，所以不影响站点首屏速度。

八、已知边界
------------
· 网页版是「可视化 + 教学」取向的移植，不做桌面版的导线碰撞、装配微调预览、托盘常驻等功能。
· 模型按包围盒装配（底座贴台面、燕尾板坐进鞍座），没有逐点还原桌面版的机械限位与中天翻转。
· 需要浏览器支持 WebGL；开启硬件加速体验最佳。
