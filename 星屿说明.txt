    · 桶       xinghuan-1521583267（南京 ap-nanjing）
    · 对象     星屿-index.pck
    · 地址     见 xingyu/web/bin-config.js 的 window.XY_PCK_URL
    · 校验     364,361,508 字节；文件头 GDPC（Godot 资源包）

               Access-Control-Allow-Methods: HEAD,GET

部署要做的事只有一件：把本包（约 39 MB）上传到 GitHub Pages。
其中 index.wasm 有 37.7 MB，超过网页拖拽上传的 25 MB 限制，
请用 GitHub Desktop / git push（单文件上限 100 MB）。

三、为什么这样拆（关键，别改）
------------------------------
· 外壳 + index.wasm + 音频 worklet 必须与页面同源：
  Godot 的音频 worklet 跨域会直接失败（实测报
  "Failed to load worklet module script ... CORS"），
  所以**不能**把整个目录都放进桶，也不能把 executable 指向桶。
· 只有 347.5 MB 的 index.pck 允许跨域，因此只把它外置到 COS。
· 桶不做网站托管、不绑自定义域名、不需要备案；
  页面在 GitHub Pages（免备案），桶只当一个文件下载源。
· COS 的 x-cos-force-download 只影响地址栏直接打开，fetch 取资源不受影响。

四、换文件位置怎么办
--------------------
只改 xingyu/web/bin-config.js：

    window.XY_PCK_URL = 'https://你的桶-appid.cos.地域.myqcloud.com/文件名.pck';

· 文件名是中文时要写 UTF-8 百分号编码，例如 星屿-index.pck →
  %E6%98%9F%E5%B1%BF-index.pck
· 若对象就叫 index.pck，也可以只给目录：
  window.XY_PCK_BASE = 'https://你的桶-appid.cos.地域.myqcloud.com';

换桶时记得同步开通：公有读、CORS（Origin *、方法 GET/HEAD、暴露 ETag 与 Content-Length）。
建议顺带把对象 Content-Type 设为 application/octet-stream（当前是 text/plain，
不影响加载，只是更规范）。

------------------

六、本机 / 教室离线使用（完全不用托管）
--------------------------------------
把「星屿浏览器版-Web导出.zip」解压，双击「启动星屿（浏览器版）.bat」，
需要本机有 Python 3。它会在本地起服务并自动打开浏览器，适合教室/局域网。

七、完整版包含什么（未做任何裁剪）
----------------------------------
· 设备：EQ6 / EQ5 / AM5N / AM3N 赤道仪；折射、牛顿、施卡、马卡主镜
        （76SAP、200PDS、D60、50SAW、Mighty Cat 71、70 APO、FF70、SQA85）；
        相机、导星、滤镜轮、电调焦、控制盒、支撑配件自由搭配；默认 OAG 导星
· 装配：预览可平移／旋转／缩放、选连接点、收放遮光罩；线缆随姿态变化并做碰撞避让
· 观测：自动观测、中天翻转、限位与归位；太阳低于 18°、目标高于 5° 才成像；
        每帧 60 秒模拟曝光；DSS2 巡天参考图
· 天空：M1–M110 与 80 个精选目标共 190 个；方位／高度／升落、日月位置、
        月相、全天星图、岁差修正均按观测地与时间计算
· 场景：北京 / 上海 / 武汉 / 阿里 / 阿塔卡马 / 堪培拉 × 六类地台，36 种组合
· 桌面：四档画质、15/30/60/120 FPS、背景透明度、置顶、鼠标穿透、托盘、中英切换
· 存档：桌面版存 %APPDATA%\TelescopeGarden\garden.json；浏览器版存 IndexedDB

八、浏览器版的已知差异（浏览器能力所限，非裁剪）
------------------------------------------------
· 鼠标穿透、窗口置顶、系统托盘、背景透明没有对应能力，
  引擎启动会打印 "Mouse passthrough not supported"，属预期提示。
· 浏览器存档是 IndexedDB，换浏览器/清缓存会丢，与桌面版不通用。
· 首次加载需下载约 385 MB（wasm 37.7 + pck 347.5），之后走缓存。
